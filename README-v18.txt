독도 시간탐험대 v18 — v17 수정본

배포: 폴더 전체를 그대로 올립니다. index.html이 game.js?v=18, passport.js?v=18, game.css?v=18, passport.css?v=18을 부릅니다.

1. 대원증·도감 PDF → 시간탐험대 여권
   - 임무를 마치면 대원증 대신 시간탐험대 여권이 발급됩니다. 엔딩 화면의 작은 여권이나 [여권 펼치기], 도감의 [시간탐험대 여권]을 누르면 열립니다.
   - 여권은 책처럼 넘겨 봅니다(다음 장·이전 장 단추, 좌우로 밀기, 방향키, 책의 왼쪽·오른쪽 끝 누르기). Esc 또는 [닫기]로 닫습니다.
   - 구성(7장)
     ① 앞표지: 남색 표지, 금색 "시간탐험대 여권 / DOKDO TIME EXPEDITION / PASSPORT", 무궁화·독도 문장, 전자여권 표시
     ② 안내 쪽 + 인적사항: 대원 사진, 로마자 이름(한글 이름을 자동 변환, 흔한 성은 KIM·LEE·PARK처럼 표기), 여권번호, 손글씨 서명, 임무 완료 도장, 기계 판독 줄
     ③ 여정 지도: 엔딩 항로도가 두 쪽에 걸쳐 펼쳐지고, 지나온 곳 7곳과 출발(1696. 4. 18. 부산포)·귀환(2026. 8. 2. 수영사적공원) 도장
     ④ 도장 1: 인물(네모 도장, 빨강) · 생물과 자원(둥근 도장, 바다 생물 파랑·식물 초록·바닷새 청록·해저 자원 보라)
     ⑤ 도장 2: 생물과 자원 나머지 · 동해안의 전설(팔각 도장) · 기록(한자 인장)
     ⑥ 기재사항 + 메모: 모은 포인트(독도 생태 조사 점수)를 손글씨로 크게 적고 동그라미, 최고 연속 명중·도감 수·받은 도장 수·항해 일수, 안용복 확인 서명
     ⑦ 뒤표지: 앞표지와 같은 남색
   - 도장에는 그 기록을 얻은 날(게임 속 날짜)이 찍힙니다. 모으지 못한 것은 찍히지 않고, 도장의 자리와 기울기는 대원 이름에 따라 달라집니다.
   - 도장 쪽을 처음 펼치면 도장이 하나씩 "쾅" 찍히며 나타납니다.
2. 메모란(맨 뒷장)
   - 뒤표지 바로 앞 쪽이 줄이 그어진 메모란입니다. 화면에서 바로 적을 수 있습니다(최대 300자).
   - 적은 글은 PDF에 파란 손글씨로 들어가고, 비워 두면 빈 줄만 인쇄되어 손으로 적을 수 있습니다.
   - 메모를 적는 동안에는 스페이스·방향키가 게임이나 여권 넘기기에 쓰이지 않습니다.
   - 메모는 게임을 새로 시작하면 지워집니다(따로 저장하지 않습니다).
3. PDF로 저장
   - 여권 창 위쪽의 [PDF로 저장]을 누르면 인쇄 화면이 열립니다. 쪽 크기는 B5 가로(250×176mm), 7쪽입니다.
   - 태블릿에서는 인쇄 화면에서 PDF 저장 또는 공유를 고르면 됩니다.
   - A4 용지로 인쇄할 때는 인쇄 화면에서 "용지에 맞추기"를 고르면 됩니다.
   - 도장 그림과 잉크 번짐은 SVG로 그려서 인쇄해도 그대로 나옵니다.
4. 화면 크기
   - 가로 화면(태블릿·PC)에서는 펼친 두 쪽을 한 번에 보고, 한 장씩 넘길 때 종이가 넘어가는 움직임이 나옵니다.
   - 휴대폰 세로 화면에서는 한 쪽씩 크게 보여 줍니다(왼쪽 쪽 → 오른쪽 쪽 → 다음 장).
5. 새 파일
   - js/passport.js, css/passport.css
   - assets/passport-stamps.png(도장 그림 27개), passport-ink.png(잉크 결), passport-leather.png(표지 가죽 결), passport-map.jpg(여권용 항로도)
   - 손글씨 글꼴은 Google Fonts의 Nanum Pen Script를 불러옵니다. 인터넷이 안 되면 기본 글꼴로 대신 나옵니다.
6. 달라진 점
   - 도감의 마지막 기록 이름이 "독도 시간탐험대 대원증"에서 "시간탐험대 여권"으로 바뀌었고, 발급 창에 여권 그림이 나옵니다.
   - 예전 대원증 카드와 A4 PDF 인쇄 코드는 뺐습니다.

확인한 것: 크롬(데스크톱 1280×800, 휴대폰 390×844, 844×390)에서 여권 넘기기·메모 입력·도감에서 열고 닫기, 크롬 PDF 저장(7쪽, B5 가로).
확인하지 못한 것: 실제 태블릿(아이패드·갤럭시 탭)의 인쇄 화면, 손글씨 글꼴이 실제로 적용된 모습(작업 환경에 인터넷이 없어 기본 글꼴로 확인).
