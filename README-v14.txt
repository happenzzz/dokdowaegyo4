독도 시간탐험대 v14 — 그래픽 개선판

실행
1. ZIP 파일을 폴더에 모두 압축 해제합니다.
2. index.html을 Chrome 또는 Edge에서 엽니다.
3. 웹 배포 시 index.html, css, js, assets, _headers를 함께 올립니다.
   예전 파일이 보이면 Ctrl+F5로 새로고침합니다.

수정 내용
- 수영사적공원·부산포·오키섬 성 밖·성 안·동래성 배경을 선명한 그림으로 교체했습니다.
- 부산포는 초가집과 소박한 나무 부두가 있는 조선 어촌으로 다시 그렸습니다.
- 부산포 이동 영역을 64칸에서 202칸으로 넓히고, 주민을 별도 스프라이트로 배치했습니다.
- 주인공 4방향 20프레임 걷기 스프라이트와 주요 인물 12칸 아틀라스를 교체했습니다.
- 이미지 해상도가 커져도 인물 표시 크기가 바뀌지 않도록 보정했습니다.
- 픽셀 확대 표시를 해제하고, 고해상도 캔버스의 이미지 보간을 개선했습니다.
- 항해 화면에 숲·바위 지형, 울릉도·독도·오키섬·암초 그림, 곡선 파도와 물살을 적용했습니다.
- 해안선을 세분화하고 같은 좌표를 육지 충돌 판정과 화면 표시에 사용합니다.
- 배 표시 크기를 조정하여 주변 지형을 더 잘 볼 수 있게 했습니다.
- 시작 전에 주요 이미지를 준비하고, 비활성 탭의 갱신과 고주사율 화면의 과속을 줄였습니다.
- 배포에 필요 없는 Git 이력은 ZIP에 포함하지 않았습니다.

검증
- JavaScript 문법 검사 완료.
- 이미지 읽기·투명도·자원 경로 검사 완료.
- 다섯 지도에서 모든 대화 대상에 접근 가능한 경로 확인.
- 부산포 실제 이동 함수, NPC 통과 방지, 안용복 대화 시작 확인.
- 로컬 Canvas 실행으로 각 장면·항해 화면·걷기 프레임 시각 점검.
- 이 작업 환경에서는 로컬 주소를 브라우저로 열 수 없어 브라우저 전체 이야기 진행과
  실제 스마트패드 터치 조작은 검증하지 못했습니다.

그림 제작
ChatGPT 내장 이미지 생성으로 원본 구도를 참고하여 재제작했습니다.
배경은 게임용 상상화이며 특정 역사 건축물이나 섬의 실측 복원도가 아닙니다.
